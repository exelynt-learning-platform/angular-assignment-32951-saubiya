Understanding Version Control, Git, and GitHub Fundamentals

1. What is Version Control?

Version control is a system that tracks changes made to files and code. It helps developers manage different versions of a project and restore old versions when needed.

2. Why Do Developers Use Git?

Developers use Git to track code changes, collaborate with team members, and manage project versions efficiently.

3. Common Problems Git Solves

  • Prevents code from being overwritten
  • Tracks project history
  • Supports teamwork and collaboration
  • Helps recover previous versions

4. Difference Between Git and GitHub

Git is a version control system used to track code changes. GitHub is an online platform used to store and share Git repositories.

5. Centralized vs Distributed Version Control

Centralized version control uses one central server to store project files. Distributed version control gives every developer a complete copy of the repository. Git is a distributed version control system.
